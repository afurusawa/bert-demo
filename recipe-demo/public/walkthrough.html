How the demo picks a starting recipe

After a head change, the lab needs new chip settings. The demo uses past calibration results to suggest where to start.

Step 1 of 5

A changed head needs calibration

After changing a recording head, the lab writes bits and reads them back. It adjusts 12 chip settings, called registers, until the bit error rate, or BER, is low enough.

The final settings are a recipe. A lower BER means fewer bits came back wrong.

The demo can suggest a starting recipe. The lab still runs the calibration suite to see whether it works.

Why keep 80 heads aside?

The demo learns from 320 completed head changes. Each log has the change type, the first electrical readings, and the 12 settings the calibration suite found.

It then checks 80 other heads. The model sees their change types and first readings. It suggests a starting recipe or refuses, without seeing the ideal settings the demo made for those heads.

If the model learned from those 80 answers, it could earn a misleading score. The demo reveals the answers only after the model makes its decisions.

Eighty is a demo choice, not a BER testing rule. The group has 79 known heads and one head from an unknown family.

Do the first readings fit the change type?

Before calibration, the tester records four electrical readings. The model checks whether they resemble past heads with the claimed change type.

It refuses to suggest settings if the type is unknown, the readings look more like another type, or they are unusually different from past heads of that type.

Passing this check lets the model offer starting settings. The calibration suite still has to test them.

Suggest settings or run the existing suite

The demo calls its learned rule a map. When the readings fit the claimed type, the map adjusts registers that usually move for that type. It fills the others with shared base values. Together, the 12 values make a starting recipe.

When the check fails, the demo gives no mapped start. It tells the lab to run the full approximate suite, the shorter calibration process it already uses.

A skipped register gets the shared base value. It does not keep the value from the last head.

Which start came closest?

For each invented head, the demo knows an ideal recipe. The bars show how far each starting method landed from it, averaged over the same 79 known heads. Shorter bars mean closer settings.

Averaging past recipes for the same change type works best here. The learned map offered starts for 53 heads. For the other 26, the demo scored a copy of the last completed recipe.

These bars score starting guesses in the demo. The calibration suite has to test a real head.
